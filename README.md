# Web Automation Project — User Login Flow

## Overview
This project automates a **user login flow** on [Automation Exercise](https://www.automationexercise.com) using **Selenium WebDriver, TestNG, and Java**.  
It uses **Page Object Model (POM)** to separate page actions from test logic, making the code more maintainable and reusable.

## Task
Automate the following steps:
1. Open the website  
2. Click **Signup / Login**  
3. Enter valid email and password  
4. Verify the user is logged in successfully  

## Features
- Page Object Model structure for maintainable code  
- Assertion to check login success  
- Automatic screenshot capture on test failure
